# Portable-core v2 provenance

`gate-source.json.gz` contains the unlabelled Gate-v2 reference registry and
source-regenerated development registry from `hotneutron/accorde` commit
`7c85e7541a3d8dfbb25fec46d96ff644c1ae72b5`, under Apache-2.0. The source
bundle records the Git paths and exact source bytes' SHA-256 digests. The
license is [LICENSE.Apache-2.0](../../../LICENSE.Apache-2.0).

Amora adapted the operation formulas from the pinned feasibility and fixture
sources into typed CPU implementations with separate portable input recipes and
oracles. Original case IDs/hashes are retained only for source crosswalks. No
native timing, training data, checkpoints, or gate assignments are included.
The independently authored H3 controls do not recreate report-only cases.
